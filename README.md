## Backend Setup (VPS)

```bash
# 1. rsync to VPS (exclude venv, Zone.Identifier)
rsync -av --exclude='venv' --exclude='*.Zone.Identifier' \
  backend/ root@43.134.107.159:/root/workspace/boost-app/

# 2. SSH to VPS
ssh root@43.134.107.159

# 3. Run setup (idempotent — safe to re-run)
cd /root/workspace/boost-app
bash setup.sh

# 4. Edit .env
nano .env
# Set: BYTEPLUS_API_KEY, JWT_SECRET

# 5. Start with PM2
pm2 start ecosystem.config.js
pm2 save

# 6. Verify
curl http://43.134.107.159:8004/boost/health
```

## Key Bug Fixes Applied (from Nebula + Aura reports)

**From Nebula:**
- Python 3.11 explicit everywhere
- bcrypt==4.0.1 pinned (not needed here — no auth, but kept as habit)
- python3.11 -m pip
- specific HTTPException detail always
- external API format verified before coding

**From Aura:**
- org.gradle.jvmargs=-Xmx2g (prevents OOM during Hilt+Compose build)
- android.useAndroidX=true explicit in gradle.properties
- NO google-services plugin (Boost doesn't use Firebase)
- Hilt plugin in BOTH root AND app build.gradle.kts
- Coil 2.x only — NO coil-network-okhttp
- NO signingConfig in debug buildType
- Theme.MaterialComponents compatible with Compose
- All mipmap icon densities generated by setup.sh
- ecosystem.config.js uses INSTALL_DIR variable, never hardcoded
- setup.sh DB password matches .env.example exactly
- google-api-python-client in requirements.txt

## AI Pipeline

```
Model 1: GLM-4V (Vision)          → product understanding
Model 2: DeepSeek-V3 (Reasoning)  → strategy + captions + hashtags
Model 3: BytePlus Image Gen       → 3 image variants (parallel)
Model 4: BytePlus Video Gen       → 2 video edits (parallel)

Models 1→2 sequential (2 depends on 1)
Models 3+4 parallel (independent)
Total target: ~25-30 seconds
```
